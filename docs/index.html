Software PLS-SEM Desktop Gratis untuk Riset Akademik di Indonesia

FreePLS Indonesia dirancang untuk memudahkan mahasiswa, dosen, dan peneliti dalam melakukan estimasi model persamaan struktural berbasis varian (PLS-SEM) secara mandiri, akurat, dan tanpa batasan lisensi komersial.

Kapabilitas Perhitungan Statistik PLS-SEM

Implementasi algoritma matriks numerik mengacu pada standar literatur Partial Least Squares (Wold, 1982; Lohmöller, 1989; Hair et al., 2017).

Outer Model

Model Pengukuran Reflektif & Formatif

Menghitung Outer Loading, Outer Weight, Cronbach's Alpha, Composite Reliability (CR rho_a & rho_c), dan Average Variance Extracted (AVE) secara otomatis untuk evaluasi validitas konvergen dan reliabilitas konstruk.

Validitas Diskriminan

HTMT & Fornell-Larcker

Tersedia matriks Fornell-Larcker Criterion, Cross Loadings per indikator, serta rasio Heterotrait-Monotrait (HTMT) dengan kriteria acuan ambang batas 0.85 atau 0.90.

Inner Model

Evaluasi Model Struktural

Menghitung Path Coefficients (koefisien jalur), Koefisien Determinasi (R-squared dan R-squared disesuaikan), Effect Size (f-squared), serta deteksi multikolinieritas melalui Inner VIF.

Uji Signifikansi

Non-Parametric Bootstrapping

Resampling otomatis subsampel acak (hingga 500+ iterasi subsampel) untuk menghasilkan standar deviasi, t-statistic empiris, dan p-value dua sisi bagi setiap jalur hubungan hipotesis.

Relevansi & Fit

Q-squared, SRMR & Indeks Model

Menyediakan estimasi relevansi prediktif Stone-Geisser (Q-squared) melalui teknik blindfolding, Standardized Root Mean Square Residual (SRMR), Normed Fit Index (NFI), dan Consistent PLS (PLSc).

Ekspor Laporan

Tabel CSV, Visual SVG & Laporan HTML

Hasil analisis dapat diekspor langsung dalam format tabel CSV untuk Microsoft Excel, diagram jalur berformat SVG beresolusi tinggi, dokumen Markdown, dan laporan HTML siap lampir untuk dokumen tugas akhir.

Alur Pengolahan Data di FreePLS

Langkah terstruktur dari dataset mentah hingga interpretasi hasil pengujian hipotesis penelitian.

1

Impor Dataset Riset

Masukkan berkas data mentah dalam format CSV atau Excel (.xlsx). Pastikan baris pertama berisi kode indikator kuesioner dan data numerik telah bersih dari nilai hilang (missing values).

2

Definisikan Konstruk & Indikator

Tambahkan variabel laten (eksogen atau endogen), kelompokkan indikator pengukuran ke masing-masing konstruk, dan pilih jenis model (reflektif atau formatif).

3

Hubungkan Jalur Struktural (Path Model)

Gambarkan panah pengaruh antar konstruk pada kanvas visual interaktif sesuai rumusan kerangka pemikiran dan hipotesis penelitian.

4

Eksekusi Algoritma PLS & Bootstrapping

Jalankan iterasi PLS Engine untuk memperoleh koefisien jalur dan outer loadings. Lanjutkan dengan kalkulasi bootstrapping untuk menguji signifikansi nilai t dan nilai p.

5

Interpretasikan & Unduh Laporan Riset

Periksa tab evaluasi model pengukuran dan model struktural. Salin tabel ringkasan atau ekspor diagram jalur SVG untuk dimasukkan ke Bab 4 laporan skripsi atau manuskrip artikel.

Dukungan AI Agent melalui Model Context Protocol (MCP)

Integrasikan FreePLS ke dalam alur kerja asisten koding dan AI Agent seperti Claude Desktop, Cursor, atau Antigravity.

FreePLS Indonesia menyertakan paket MCP Server bawaan yang berlokasi pada direktori mcp-server/. Server ini menyediakan tool analitik siap panggil:

  • pls_full_pipeline: Membaca file data, mengelompokkan variabel, menjalankan iterasi PLS dan Bootstrapping, lalu menulis laporan lengkap (HTML, CSV, SVG) secara otonom.
  • pls_calculate: Menjalankan estimasi matriks PLS murni pada model yang telah terkonfigurasi.
  • pls_bootstrap: Menghasilkan uji signifikansi empiris dengan sampling acak berulang.

Dengan protokol MCP, AI Agent dapat membantu memeriksa anomali data, memverifikasi kriteria validitas, dan mendokumentasikan hasil temuan penelitian secara terstruktur.

claude_desktop_config.json 
{
  "mcpServers": {
    "freepls": {
      "command": "node",
      "args": [
        "C:\\Users\\Username\\AppData\\Local\\Programs\\FreePLS Indonesia\\resources\\mcp-server\\index.js"
      ]
    }
  }
}

Spesifikasi & Kebutuhan Sistem

Aplikasi berdiri sendiri (standalone) tanpa ketergantungan runtime eksternal.

Sistem Operasi Windows 10, Windows 11 (arsitektur 64-bit)
Format Distribusi Installer berkas tunggal (.exe) berbasis Electron
Kebutuhan Memori (RAM) Minimum 4 GB RAM (direkomendasikan 8 GB untuk dataset besar & bootstrapping > 1000)
Penyimpanan Hard Disk Minimum 300 MB ruang kosong untuk instalasi dan basis data proyek lokal
Konektivitas Internet Tidak dibutuhkan saat eksekusi. Seluruh perhitungan matriks dan penyimpanan SQLite berjalan offline di komputer lokal
Format Berkas Masukan CSV (pemisah koma atau titik koma), Microsoft Excel (.xlsx)
Format Luaran Hasil CSV, SVG grafik vektor, dokumen Markdown, dan laporan HTML interaktif

Pertanyaan yang Sering Diajukan (FAQ)

Informasi praktis seputar penggunaan dan lisensi perangkat lunak.

Apakah FreePLS Indonesia benar-benar gratis untuk mahasiswa?
Ya. FreePLS Indonesia dilisensikan di bawah Creative Commons Attribution-NonCommercial 4.0 International (CC BY-NC 4.0). Mahasiswa, dosen, dan peneliti independen dapat menggunakannya secara cuma-cuma tanpa batas waktu untuk penyusunan skripsi, tesis, disertasi, maupun artikel jurnal non-komersial.
Apakah data penelitian saya dikirim ke server daring (cloud)?
Tidak. FreePLS adalah aplikasi desktop lokal. Seluruh pembacaan berkas data, kalkulasi aljabar linier, dan penyimpanan model ke database SQLite berjalan sepenuhnya di komputer Anda tanpa memerlukan koneksi internet.
Apakah hasil perhitungannya sesuai dengan kaidah literatur PLS-SEM?
Ya. Engine komputasi FreePLS mengimplementasikan persamaan standar algoritma PLS Wold dan Lohmöller: normalisasi data, inner weighting schemes (path/centroid), estimasi outer loadings dan weights, kalkulasi Fornell-Larcker, serta bootstrapping non-parametrik untuk uji hipotesis sesuai rekomendasi Hair et al. (2017).
