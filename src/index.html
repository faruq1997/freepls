calculate

Algoritma PLS-SEM

Estimasi parameter model pengukuran (Outer Model) dan model struktural (Inner Model): Outer Loading, AVE, Composite Reliability, HTMT, VIF, dan R².

shuffle

Bootstrapping (Uji Hipotesis)

Uji signifikansi koefisien jalur (T-Statistic & P-Values), pengujian hipotesis pengaruh langsung, dan efek mediasi spesifik (Specific Indirect Effects).

psychology

Uji Validitas & Reliabilitas Butir

Pengujian butir instrumen kuesioner pada tahap pra-riset: Korelasi Pearson (r-Hitung vs r-Tabel), Corrected Item-Total, dan Cronbach's Alpha if Item Deleted.

✓ Evaluasi otomatis terhadap r-Tabel Kritis sesuai derajat kebebasan ($df = N-2$).

✓ Diagnosa butir kuesioner yang gugur beserta rekomendasi eliminasi.

✓ Disertai rumus matematis, tahapan komputasi, dan referensi metodologi.

analytics

Statistik Deskriptif & Normalitas

Tabel ringkasan deskriptif variabel penelitian: Mean, Median, Modus, Standar Deviasi, Varians, Min, Max, TCR (%), Skewness, dan Kurtosis (Uji Normalitas Univariat).

✓ Nilai Tingkat Capaian Responden (TCR) beserta interpretasi kategori.

✓ Uji rasio Z-Score Skewness & Kurtosis (± 1.96).

✓ Draf narasi hasil analisis data yang siap disalin untuk laporan.

tune

Uji Pengaruh Moderasi & Simple Slope

Pengujian efek moderasi Two-Stage / Product Indicator ($X \times M \rightarrow Y$), efek ukuran $f^2$, dan pembuatan grafik interaktif Simple Slope Plot (±1 SD).

✓ Analisis interaksi variabel moderasi terhadap hubungan kausalitas.

✓ Visualisasi grafik garis slope pada level moderator Rendah, Rata-rata, & Tinggi.

✓ Evaluasi tipe efek (Strengthening vs Dampening effect).

tune

Consistent PLS (PLSc)

Koreksi attenuation bias pada konstruk reflektif menggunakan Dijkstra-Henseler ρ_A. Menghasilkan koefisien jalur terkoreksi dan korelasi disattenuated — disarankan saat membandingkan hasil dengan CB-SEM.

✓ Menghitung ρ_A (rho_A) per konstruk reflektif.

✓ Path coefficients PLSc via OLS pada korelasi laten terkoreksi.

map

IPMA — Importance-Performance Map

Peta kuadran: sumbu-X = performa indikator (rerata rescaled 0–100), sumbu-Y = total efek ke konstruk target. Identifikasi variabel mana yang penting tapi kinerjanya rendah untuk diprioritaskan.

group

Multi-Group Analysis (MGA)

Bandingkan koefisien jalur antar dua kelompok responden (mis. laki-laki vs perempuan, kota vs desa) menggunakan uji parametrik Henseler. Wajib ada untuk penelitian komparatif.

batch_prediction

PLSpredict — Relevansi Prediktif

Evaluasi kemampuan prediksi out-of-sample menggunakan k-fold cross-validation. Menghasilkan RMSE, MAE, dan Q²_predict per variabel endogen (Hair et al. 2019).

warning_amber

Harman Single Factor (CMV)

Uji Common Method Bias paling umum diminta reviewer jurnal Indonesia. Jika variansi faktor pertama > 50%, CMV dapat menjadi ancaman validitas.

✓ Eigenvalue decomposition seluruh indikator.

✓ Kesimpulan otomatis beserta rekomendasi tindak lanjut.

table_chart

Ekspor Tabel APA 7

Generate empat tabel siap-tempel ke Word/LaTeX: outer loadings, reliabilitas & AVE, HTMT (lower triangle), serta koefisien jalur & R² dalam format APA edisi ke-7.

✓ Tabel 1: Outer Loadings Matrix

✓ Tabel 2: AVE, CR, Cronbach α

✓ Tabel 3: HTMT Discriminant Validity

✓ Tabel 4: Path Coefficients, R², f²

1. Uji Validitas Butir (Korelasi Pearson Product Moment)

              

                Digunakan untuk menguji apakah setiap butir pernyataan kuesioner berkorelasi linier positif dan signifikan dengan skor total konstruk.
              

              

                r_xy = [ N ∑XY - (∑X)(∑Y) ] / √[ [ N ∑X² - (∑X)² ] [ N ∑Y² - (∑Y)² ] ]
              

              

                Kriteria Keputusan: Butir dinyatakan Valid jika r-Hitung > r-Tabel pada taraf signifikansi α = 0.05 ($df = N - 2$) dan nilai $p < 0.05$ (Sugiyono, 2019; Azwar, 2018).
              


              
2. Korelasi Butir-Total Terkoreksi (Corrected Item-Total Correlation)

              

                r_i(total-i) = [ r_i,total · s_total - s_i ] / √[ s_total² + s_i² - 2 · r_i,total · s_total · s_i ]
              

              

                Kriteria Keputusan: Mencegah korelasi semu (*spurious correlation*) karena skor butir $i$ tidak diikutsertakan dalam skor total. Butir memiliki daya beda yang baik jika r_koreksi ≥ 0.300 (Azwar, 2018; Nunnally & Bernstein, 1994).
              


              
3. Uji Reliabilitas (Cronbach's Alpha) & Alpha if Item Deleted

              

                α = [ k / (k - 1) ] × [ 1 - ( ∑ s_i² / s_total² ) ]
              

              

                Kriteria Keputusan: Konstruk dinyatakan reliabel jika koefisien Cronbach's Alpha ≥ 0.700 (Hair et al., 2022; Ghozali, 2021). Kolom Alpha if Item Deleted menunjukkan nilai reliabilitas jika butir tertentu dihapus (membantu mengidentifikasi butir penggugur).
