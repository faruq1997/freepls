lightbulbApa itu PLS-SEM?

                

              

              

                Partial Least Squares – Structural Equation Modeling (PLS-SEM) adalah metode analisis
                multivariat yang mengestimasi model jalur (path model) menggunakan pendekatan berbasis komponen. PLS-SEM
                cocok untuk:
              

              
    
                
  • Sampel kecil (minimal ≥ 30 responden, ideal ≥ 100)
    • 
                
  • Data tidak memenuhi asumsi normalitas multivariat
    • 
                
  • Model kompleks dengan banyak konstruk dan indikator
    • 
                
  • Tujuan prediksi dan eksplorasi teori
    • 
              

              

                info
                Gunakan CB-SEM (LISREL, AMOS) bila tujuan konfirmasi teori dengan asumsi
                  normalitas terpenuhi dan sampel besar (≥ 200). Gunakan PLS-SEM untuk prediksi,
                  eksplorasi, dan kondisi data terbatas.
              


              

                Persamaan Dasar Model PLS
                

                  y = B η + Γ ξ + ζ
                

                

                  y = skor indikator endogen  |  η = variabel laten endogen
                   |  ξ = variabel laten eksogen

                  B = matriks koefisien jalur antar konstruk endogen  |  Γ =
                  matriks koefisien jalur eksogen ke endogen

                  ζ = vektor error (residual) struktural
                

              

            


            
            

              

                

                  Model Pengukuran
                  
cableOuter Loading (Faktor Loading)

                

              

              

                Outer loading adalah korelasi antara indikator dengan konstruk latennya. Pada model reflektif,
                outer loading mencerminkan seberapa kuat sebuah indikator merepresentasikan konstruknya.
              

              

                Rumus Outer Loading (Pearson Correlation)
                

                  λj =
                  
                    Σ(xj − x̄j)(η − η̄)
                    √Σ(xj − x̄j)² · Σ(η − η̄)²
                  
                

                

                  λj = outer loading indikator ke-j  | 
                  xj = nilai indikator  |  η = skor konstruk
                  laten
                

              

              

                check_circle
                Kriteria Penerimaan: Outer loading ≥ 0.70 (Hair et al., 2022). Nilai 0.40–0.69
                  masih dapat diterima bila AVE dan CR konstruk tetap memenuhi syarat. Loading < 0.40 → indikator
                  dipertimbangkan untuk dihapus.
              

            


            
            

              

                

                  Model Pengukuran
                  
verifiedAVE — Average Variance Extracted

                

              

              

                AVE mengukur proporsi rata-rata variansi indikator yang ditangkap oleh konstruk laten dibandingkan
                dengan variansi error. AVE merupakan indikator utama validitas konvergen.
              

              

                Rumus AVE (Fornell & Larcker, 1981)
                

                  AVE =
                  
                    Σ λj²
                    Σ λj² + Σ var(εj)
                  
                  =
                  
                    Σ λj²
                    n
                  
                

                

                  λj = outer loading indikator ke-j  |  n =
                  jumlah indikator konstruk  |  var(εj) = variansi error = 1 −
                  λj²
                

              

              

                check_circle
                Kriteria Penerimaan: AVE ≥ 0.50 (Fornell & Larcker, 1981). Artinya konstruk
                  menjelaskan lebih dari 50% variansi indikatornya (signal > noise).
              

            


            
            

              

                

                  Model Pengukuran
                  
securityComposite Reliability (CR / ρc)
                  

                

              

              

                Composite Reliability mengukur konsistensi internal suatu konstruk reflektif. Berbeda dari Alpha
                Cronbach, CR memperhitungkan perbedaan bobot outer loading tiap indikator sehingga lebih akurat untuk
                PLS.
              

              

                Rumus Composite Reliability (Werts et al., 1974)
                

                  CR =
                  
                    (Σ λj)²
                    (Σ λj)² + Σ (1 − λj²)
                  
                

                

                  λj = outer loading indikator ke-j  |  (1 −
                    λj²) = variansi error indikator ke-j
                

              

              

                check_circle
                Kriteria Penerimaan: CR ≥ 0.70 (Hair et al., 2022). Nilai CR > 0.95 perlu
                  dicermati karena mengindikasikan indikator yang terlalu mirip (redundancy). Range ideal:
                  0.70–0.95.
              

            


            
            

              

                

                  Uji Instrumen
                  
verified_userCronbach's Alpha (α)

                

              

              

                Cronbach's Alpha mengukur konsistensi internal dengan asumsi semua indikator memiliki bobot sama (equal
                weighting). Dalam PLS-SEM, Alpha Cronbach digunakan sebagai batas bawah reliabilitas (lower bound).
              

              

                Rumus Cronbach's Alpha
                

                  α =
                  
                    k
                    k − 1
                  
                  ×
                  (1 −
                  
                    Σ si²
                    stotal²
                  
                  )
                

                

                  k = jumlah item (indikator)  |  si² = variansi
                  item ke-i  |  stotal² = variansi total skor
                

              

              

                Alpha if Item Deleted
                

                  α(j) = α saat indikator ke-j dihapus dari konstruk
                

                

                  Jika α(j) > αtotal, maka indikator ke-j menurunkan reliabilitas →
                  pertimbangkan penghapusan
                

              

              

                check_circle
                Kriteria: α ≥ 0.70 untuk riset dasar; α ≥ 0.80 untuk riset terapan (Hair et al.,
                  2022). Gunakan bersama CR — keduanya harus memenuhi batas minimum.
              

            


            
            

              

                

                  Model Pengukuran
                  
compare_arrowsValiditas Diskriminan

                

              

              

                Validitas diskriminan memastikan bahwa setiap konstruk unik dan tidak berkorelasi terlalu tinggi dengan
                konstruk lain. Tiga metode utama yang digunakan:
              


              
① Cross Loadings
              

              

                check_circle
                Loading setiap indikator pada konstruk sendiri harus lebih tinggi dari
                  loading-nya terhadap konstruk lain. (Chin, 1998)
              


              
② Fornell-Larcker
                Criterion

              

                Syarat Fornell-Larcker
                

                  √AVEA > rAB
                

                

                  Akar AVE setiap konstruk (A) harus > korelasi konstruk tersebut dengan konstruk lain
                  (rAB)
                

              


              
③ HTMT —
                Heterotrait-Monotrait Ratio (Rekomendasi Terkini)

              

                Rumus HTMT (Henseler et al., 2015)
                

                  HTMTjk =
                  
                    r̄HeteroTrait
                    √r̄MT,A · r̄MT,B
                  
                

                

                  r̄HeteroTrait = rata-rata korelasi antar indikator lintas konstruk yang
                  berbeda

                  r̄MT = rata-rata korelasi monotrait (antar indikator dalam
                  konstruk yang sama)
                

              

              

                check_circle
                Kriteria HTMT: HTMT < 0.85 (kriteria konservatif, Henseler et al., 2015) atau
                  HTMT < 0.90 (kriteria moderat, Gold et al., 2001). HTMT adalah standar validitas diskriminan
                  terbaru yang direkomendasikan menggantikan Fornell-Larcker untuk PLS-SEM.
              

            


            
            

              

                

                  Dasar PLS-SEM
                  
settings_suggestAlgoritma PLS-SEM

                

              

              

                Algoritma PLS-SEM bekerja secara iteratif untuk mengestimasi skor konstruk laten. Prosesnya terdiri dari
                dua tahap iterasi:
              

              
    
                
  1. Inisialisasi: Setiap konstruk diberi bobot awal (outer weight = 1 / √jumlah
                  indikator)
    2. 
                
  2. Iterasi Inner (Structural): Skor konstruk diperbarui berdasarkan hubungan
                  struktural menggunakan centroid/factor/path weighting scheme
    3. 
                
  3. Iterasi Outer (Measurement): Bobot indikator diperbarui berdasarkan korelasi dengan
                  skor konstruk saat ini
    4. 
                
  4. Uji Konvergensi: Ulang langkah 2–3 hingga perubahan outer weight <
                  10−5
    5. 
                
  5. Estimasi Akhir: Hitung outer loading, koefisien jalur (OLS), dan ukuran model fit
                
    6. 
              

              

                Outer Weight (Mode A — Reflektif)
                

                  wj =
                  
                    Cov(xj, η)
                    Σ Cov(xj, η)²
                  
                

                

                  wj = bobot outer indikator ke-j  |  Mode A (reflektif): bobot
                  proporsional korelasi dengan konstruk

                  Mode B (formatif): bobot dihitung via OLS regresi indikator terhadap konstruk
                

              

            


            
            

              

                

                  Model Struktural
                  
trending_upKoefisien Jalur (Path Coefficients)

                

              

              

                Koefisien jalur (β) merepresentasikan kekuatan dan arah hubungan antar konstruk laten dalam model
                struktural. Dihitung menggunakan Ordinary Least Squares (OLS) dari skor konstruk laten.
              

              

                Estimasi OLS — Koefisien Jalur
                

                  β = (XTX)−1 XTY
                

                

                  X = matriks skor konstruk eksogen  |  Y = vektor skor
                  konstruk endogen

                  Hasilnya adalah koefisien terstandarisasi karena skor laten sudah dalam unit standar
                

              

              

                check_circle
                Interpretasi: β = 0.20 (efek kecil), β = 0.50 (efek sedang), β = 0.80 (efek
                  besar) — Hair et al. (2022). Signifikansi diuji via bootstrapping (t-stat > 1.96 untuk α =
                  0.05).
              

            


            
            

              

                

                  Model Struktural
                  
donut_largeR² — Koefisien Determinasi

                

              

              

                R² (R-squared) mengukur proporsi variansi konstruk endogen yang dijelaskan oleh seluruh variabel
                prediktor (eksogen) dalam model. R² berkisar antara 0 dan 1.
              

              

                Rumus R²
                

                  R² = 1 −
                  
                    SSres
                    SStot
                  
                  =
                  
                    Σ(Ŷ − Ȳ)²
                    Σ(Y − Ȳ)²
                  
                

                

                  SSres = jumlah kuadrat residual  | 
                  SStot = jumlah kuadrat total

                  Ŷ = nilai prediksi  |  Ȳ = rata-rata nilai aktual
                

              

              

                check_circle
                Kriteria Hair et al. (2022): R² ≥ 0.75 = substansial (kuat); 0.50–0.74 = moderat;
                  0.25–0.49 = lemah; < 0.25 = sangat lemah. Batas minimum yang dapat diterima bergantung pada
                  disiplin ilmu.
              


              

                R² Disesuaikan (Adjusted R²)
                

                  R²adj = 1 − (1 − R²) ×
                  
                    n − 1
                    n − k − 1
                  
                

                

                  n = jumlah sampel  |  k = jumlah variabel prediktor

                  R²adj mengoreksi bias akibat penambahan variabel prediktor; lebih konservatif dari R²
                

              

            


            
            

              

                

                  Model Struktural
                  
zoom_inf² — Ukuran Efek (Effect Size)

                

              

              

                f² mengukur seberapa besar pengaruh satu konstruk prediktor terhadap R² konstruk endogen. f² melengkapi
                informasi koefisien jalur dengan mengukur kontribusi relatif tiap prediktor.
              

              

                Rumus f² (Cohen, 1988)
                

                  f² =
                  
                    R²included − R²excluded
                    1 − R²included
                  
                

                

                  R²included = R² saat prediktor X disertakan  | 
                  R²excluded = R² saat prediktor X dihapus
                

              

              

                check_circle
                Kriteria Cohen (1988): f² = 0.02 (kecil), f² = 0.15 (sedang), f² = 0.35 (besar).
                  Nilai di bawah 0.02 menandakan konstruk prediktor tidak memberikan kontribusi praktis berarti.
              

            


            
            

              

                

                  Model Pengukuran
                  
warning_amberVIF — Variance Inflation Factor

                

              

              

                VIF digunakan untuk mendeteksi multikolinearitas antar indikator (khususnya pada model
                formatif) dan antar konstruk prediktor dalam model struktural.
              

              

                Rumus VIF
                

                  VIFj =
                  
                    1
                    1 − R²j
                  
                

                

                  R²j = R² dari regresi indikator ke-j terhadap semua indikator lain dalam
                  konstruk yang sama
                

              

              

                check_circle
                Kriteria: VIF < 5.0 (Hair et al., 2022, standar umum PLS-SEM). Nilai yang
                  lebih konservatif: VIF < 3.3. VIF ≥ 5 mengindikasikan multikolinearitas masalah yang perlu
                  ditangani (hapus/gabung indikator).
              

            


            
            

              

                

                  Bootstrap & Inferensi
                  
shuffleBootstrapping — Uji Signifikansi

                

              

              

                PLS-SEM tidak mengasumsikan distribusi normal, sehingga uji signifikansi dilakukan melalui
                bootstrapping nonparametrik. Prosedur: sampling ulang dengan pengembalian (with
                replacement) dari data asli sebanyak B iterasi (minim 500, disarankan 5000).
              

              
    
                
  1. Sampling B sampel bootstrap (ukuran sama dengan data asli, with replacement)
    2. 
                
  2. Hitung estimasi parameter (β) pada tiap sampel bootstrap
    3. 
                
  3. Hitung standar error dari distribusi B estimasi bootstrap
    4. 
                
  4. Hitung t-statistik dan CI 95%
    5. 
              

              

                t-Statistik Bootstrap
                

                  t =
                  
                    β̂original
                    SEbootstrap
                  
                

                

                  β̂original = estimasi koefisien dari sampel asli  | 
                  SEbootstrap = standar deviasi dari distribusi estimasi bootstrap
                

              

              

                Confidence Interval 95% (Bias-Corrected Percentile)
                

                  CI 95% = [ P2.5%, P97.5% ] dari distribusi bootstrap
                

                

                  Jalur signifikan jika CI 95% tidak melewati nol. Setara dengan p < 0.05 (dua sisi).
                

              

              

                check_circle
                Kriteria Signifikansi: |t| > 1.96 (p < 0.05, dua sisi) atau CI 95% tidak
                  mencakup nilai nol. Gunakan minimum 500 bootstrap; Hair et al. (2022) merekomendasikan 5000.
              

            


            
            

              

                

                  Model Struktural
                  
mediationEfek Mediasi & VAF

                

              

              

                Efek mediasi terjadi ketika variabel M menjadi perantara hubungan antara X dan Y. Kekuatan mediasi
                diukur menggunakan Variance Accounted For (VAF).
              

              

                Efek Tidak Langsung (Indirect Effect)
                

                  IE = a × b
                

                

                  a = koefisien jalur X → M  |  b = koefisien jalur M →
                  Y

                  TE (Total Effect) = DE + IE = c' + (a × b)
                

              

              

                VAF — Variance Accounted For
                

                  VAF =
                  
                    IE
                    TE
                  
                  =
                  
                    a × b
                    a × b + c'
                  
                

                

                  c' = efek langsung X → Y saat M hadir
                

              

              

                check_circle
                Interpretasi VAF (Hair et al., 2022): VAF < 0.20 = tidak ada mediasi;
                  0.20–0.80 = mediasi parsial; > 0.80 = mediasi penuh. Signifikansi IE diuji via bootstrap CI 95%
                  (Preacher & Hayes, 2008).
              

            


            
            

              

                

                  Analisis Lanjutan
                  
tuneConsistent PLS (PLSc)

                

              

              

                PLSc mengoreksi bias atenuasi (attenuation bias) yang terjadi pada PLS-SEM standar untuk
                konstruk reflektif menggunakan koefisien reliabilitas Dijkstra-Henseler (ρA). Hasil PLSc
                konsisten secara statistik dan mendekati estimasi CB-SEM.
              

              

                Rumus ρ_A (Dijkstra-Henseler, 2015)
                

                  ρA =
                  
                    w'Sw − 1
                    w'Sw − w'w
                  
                

                

                  w = vektor outer weight  |  S = matriks korelasi antar
                  indikator dalam konstruk

                  w'Sw = bentuk kuadratik: weighted sum of inter-indicator correlations

                  w'w = jumlah kuadrat weight
                

              

              

                check_circle
                ρA ≥ 0.70 mengindikasikan reliabilitas yang cukup. PLSc direkomendasikan saat model
                  reflektif dibandingkan dengan hasil CB-SEM atau saat peneliti menginginkan estimasi yang konsisten
                  secara statistik (Dijkstra & Henseler, 2015).
              

            


            
            

              

                

                  Analisis Lanjutan
                  
mapIPMA — Importance-Performance Map Analysis

                

              

              

                IPMA menggabungkan informasi importance (total efek ke target) dan
                performance (rata-rata skor rescaled 0–100) untuk mengidentifikasi prioritas perbaikan.
                Variabel yang penting (importance tinggi) tetapi berkinerja rendah (performance rendah) memerlukan
                perhatian utama.
              

              

                Importance = Total Effect (Hair et al., 2019)
                

                  ImportanceX→Y = DEXY + Σ (IEXMY)
                

              

              

                Performance — Rescaling (0–100)
                

                  Pi =
                  
                    x̄i − xmin
                    xmax − xmin
                  
                  × 100
                

                

                  x̄i = rata-rata indikator  | 
                  xmin/max = nilai minimum/maksimum teoretis atau empiris skala
                

              

              

                check_circle
                Interpretasi: Kuadran Kiri Atas = prioritas utama (tingkatkan segera). Kanan Atas
                  = pertahankan. Kiri Bawah = prioritas rendah. Kanan Bawah = potensi terlalu berlebih. (Ringle &
                  Sarstedt, 2016)
              

            


            
            

              

                

                  Analisis Lanjutan
                  
groupMulti-Group Analysis (MGA)

                

              

              

                MGA menguji apakah koefisien jalur berbeda secara signifikan antara dua atau lebih kelompok (misal: pria
                vs wanita, kota vs desa). Metode yang digunakan adalah Henseler's Parametric MGA.
              

              

                t-Statistik MGA (Henseler et al., 2009)
                

                  tMGA =
                  
                    |β̂G1 − β̂G2|
                    √SE²G1 + SE²G2
                  
                

                

                  β̂G1, β̂G2 = koefisien jalur grup 1 dan 2  | 
                  SEG1, SEG2 = standar error bootstrap masing-masing grup

                  Derajat kebebasan: df = nG1 + nG2 − 4
                

              

              

                check_circle
                Kriteria: p < 0.05 → koefisien jalur berbeda signifikan antar kelompok.
                  Prasyarat: measurement invariance harus diuji terlebih dahulu (Henseler et al., 2016).
                  Minimal 5 sampel per kelompok; ideal ≥ 30 per kelompok.
              

            


            
            

              

                

                  Analisis Lanjutan
                  
batch_predictionPLSpredict — Relevansi Prediktif
                    Out-of-Sample

                

              

              

                PLSpredict menggunakan k-fold cross-validation untuk mengevaluasi kemampuan prediksi model PLS-SEM
                secara out-of-sample. Berbeda dari Q² Blindfolding (in-sample), PLSpredict memberikan ukuran
                prediksi yang lebih realistis.
              

              

                Q²_predict (Hair et al., 2019)
                

                  Q²predict = 1 −
                  
                    Σ(y − ŷPLS)²
                    Σ(y − ȳ)²
                  
                

              

              

                RMSE (Root Mean Square Error)
                

                  RMSE =
                  
                    √
                    
                      
                        Σ(y − ŷ)²
                        n
                      
                    
                  
                

                
Bandingkan RMSEPLS dengan RMSENaive (prediksi
                  menggunakan mean — naive benchmark). Model PLS lebih baik jika RMSEPLS <
                  RMSENaive.

              

              

                check_circle
                Kriteria Relevansi Prediktif: Q²predict > 0 DAN RMSEPLS
                  < RMSENaive → model memiliki relevansi prediktif. Q²predict ≥ 0.25 (medium),
                  ≥ 0.50 (besar) — Shmueli et al. (2019).
              

            


            
            

              

                

                  Analisis Lanjutan
                  
warning_amberHarman Single Factor Test — CMV

                

              

              

                Common Method Bias (CMV) terjadi saat variansi data lebih banyak dijelaskan oleh metode
                pengumpulan data (misal: kuesioner tunggal) daripada konstruk yang diukur. Harman Single Factor Test
                adalah pengujian yang paling sering diminta reviewer jurnal Indonesia.
              

              

                Prosedur Harman (Podsakoff et al., 2003)
                

                  % Variansi F1 =
                  
                    λ1
                    k
                  
                  × 100%
                

                

                  λ1 = eigenvalue terbesar dari matriks korelasi seluruh indikator (Power
                  Iteration)

                  k = jumlah total indikator dalam model
                

              

              

                check_circle
                Kriteria: Jika variansi faktor pertama < 50% → CMV tidak menjadi ancaman
                  serius. Jika ≥ 50% → CMV berpotensi mengancam validitas, pertimbangkan prosedur mitigasi (Harman,
                  1967; Podsakoff et al., 2003).
              

            


            
            

              

                

                  Statistik Deskriptif
                  
bar_chartStatistik Deskriptif

                

              

              

                

                  Mean (Rata-rata)
                  

                    x̄ =
                    Σ xin
                  

                

                

                  Standar Deviasi (SD)
                  

                    s =
                    √
                        Σ(xi − x̄)²n − 1
                      
                  

                

                

                  Z-Score (Standarisasi)
                  

                    zi =
                    xi − x̄s
                  

                  
|z| > 3.0 = outlier ekstrem

                

                

                  SE Mean (Standard Error of Mean)
                  

                    SE =
                    s√n
                  

                  
Ketidakpastian estimasi rata-rata populasi

                

                

                  Skewness (Kemencengan)
                  

                    Sk =
                    
                      Σ(xi−x̄)³n
                      s³
                    
                  

                  
Normal jika |Sk| < 2.0 (Hair et al., 2022)

                

                

                  Excess Kurtosis
                  

                    K =
                    
                      Σ(xi−x̄)⁴n
                      s⁴
                    
                    − 3
                  

                  
Normal jika |K| < 7.0 (Hair et al., 2022)

                

              

            


            
            

              

                

                  Praproses Data
                  
policyDeteksi & Penanganan Outlier

                

              

              

                Outlier adalah observasi yang jauh menyimpang dari pola umum data dan dapat mendistorsi hasil analisis.
                Dua pendekatan utama:
              

              
Deteksi — Z-Score
                Univariat

              

                

                  zi =
                  xi − x̄s
                

                
Outlier moderat: |z| ≥ 2.5  |  Outlier ekstrem: |z| ≥ 3.0
                  (Hair et al., 2022)

              

              
Penanganan ① Data
                Trimming (Penghapusan)

              

                delete_outline
                Hapus baris yang memiliki |z| ≥ threshold pada kolom manapun. Efektif jika outlier adalah error
                  entri data atau responden tidak serius mengisi kuesioner.
              

              
Penanganan ②
                Winsorizing (Pembatasan Nilai)

              

                

                  xi* = max(x̄ − k·s, min(xi, x̄ + k·s))
                

                
k = threshold Z-score (misal 3.0). Nilai ekstrem
                  diganti dengan batas atas/bawah — ukuran sampel N tetap terjaga.

              

            


            
            

              

                

                  Analisis Lanjutan
                  
balanceUji Normalitas Multivariat Mardia & Justifikasi PLS

                

              

              

                Uji Mardia (1970) menguji asumsi normalitas multivariat pada data indikator penelitian. Jika data terbukti tidak berdistribusi normal multivariat (p < 0.05), maka penggunaan metode non-parametrik PLS-SEM terjustifikasi secara ilmiah dibandingkan CB-SEM (Hair et al., 2019, 2021).
              

              

                Mardia Multivariate Skewness (b1,p)
                

                  b1,p = 
                  
                    1
                    n²
                  
                  Σ Σ [(xi − x̄)′ S⁻¹ (xj − x̄)]³
                

                
Uji Chi-Square: χ² = (n · b1,p) / 6 dengan df = p(p + 1)(p + 2) / 6

              

              

                Mardia Multivariate Kurtosis (b2,p)
                

                  b2,p = 
                  
                    1
                    n
                  
                  Σ [(xi − x̄)′ S⁻¹ (xi − x̄)]²
                

                
Uji Normal Z: Z = [b2,p − p(p + 2)] / √[8p(p + 2) / n]

              

              

                check_circle
                Pedoman: Jika p < 0.05 pada skewness atau kurtosis, data tidak berdistribusi normal multivariat → FreePLS menyediakan draf narasi siap salin untuk bab metodologi penelitian Anda.
              

            


            
            

              

                

                  Model Pengukuran
                  
checklistEvaluasi Model Pengukuran Formatif (Mode B)

                

              

              

                Konstruk formatif tidak dievaluasi dengan Cronbach's Alpha atau AVE karena indikator bersifat kausal dan tidak harus saling berkorelasi tinggi. Evaluasi difokuskan pada multikolinearitas dan kontribusi indikator.
              

              

                info
                1. Multikolinearitas (Indicator VIF): VIF ≤ 3.3 (ideal/bebas masalah), 3.3 < VIF ≤ 5.0 (dapat diterima), VIF > 5.0 (kritis/harus diatasi).
              

              

                check_circle
                2. Aturan Retensi (Hair et al., 2021): Pertahankan jika Outer Weight signifikan (p < 0.05). Jika tidak signifikan namun Outer Loading ≥ 0.50, indikator tetap dipertahankan. Jika Outer Loading < 0.50 dan bobot tidak signifikan, pertimbangkan eliminasi.
              

            


            
            

              

                

                  Analisis Lanjutan
                  
account_treeHigher-Order Constructs (HOC / Dimensi)

                

              

              

                Hierarchical Component Models (HCM) memungkinkan pemodelan konstruk berdimensi ganda (misal: variabel Kualitas Layanan memiliki 5 dimensi LOC). FreePLS mengimplementasikan Two-Stage Approach (Sarstedt et al., 2019):
              

              

                Tahap 1: Model dasar dieksekusi untuk mendapatkan skor laten baku (LVS) masing-masing LOC.

                Tahap 2: Skor LOC digunakan sebagai indikator manifest dari HOC, memungkinkan evaluasi validitas HOC dan pengaruh struktural ke konstruk endogen tujuan.
              

            


            
            

              

                

                  Analisis Lanjutan
                  
filter_altNecessary Condition Analysis (NCA)

                

              

              

                NCA (Dul, 2016) menguji apakah sebuah prediktor X merupakan syarat perlu (necessary condition) — bukan hanya syarat cukup — bagi tercapainya hasil Y. Menggunakan batas atas (Ceiling Envelopment CE-FDH) untuk menghitung effect size d dan Tabel Hambatan (Bottleneck Table).
              

              

                Effect Size d (Dul, 2016)
                

                  d = 
                  
                    Area Zona Kosong di Atas Ceiling (C)
                    Total Area Ruang Lingkup (Scope S)
                  
                

                
d < 0.1 (diabaikan), 0.1 ≤ d < 0.3 (sedang), 0.3 ≤ d < 0.5 (besar), d ≥ 0.5 (sangat besar)

                info
                

                  Alur Sistematis Pengujian Instrumen Penelitian
                    (Kuesioner):
                  Pengujian instrumen dilakukan untuk memastikan bahwa alat ukur yang digunakan memenuhi prinsip
                  keabsahan (validitas) dan keandalan (reliabilitas) sebelum data digunakan dalam
                  estimasi model struktural PLS-SEM.
                

              


              
              

                

                  Tahap 1
                  
Agregasi Skor Total Konstruk (Komposit Responden)

                

                

                  Untuk setiap responden ke-j (j = 1, 2, ..., N), skor dari k butir
                  pertanyaan yang mengukur konstruk yang sama dijumlahkan untuk menghasilkan skor total komposit
                  (Yj):
                

                

                  

                    Yj = ∑i=1k Xij =
                    X1j + X2j + ... + Xkj
                  

                

                

                  Keterangan: Xij adalah skor respon butir ke-i dari
                  responden ke-j; k adalah banyaknya butir indikator; Yj adalah
                  skor total konstruk untuk responden ke-j.
                

              


              
              

                

                  Tahap 2
                  
Komputasi Rata-rata dan Varians Butir serta Total

                

                

                  Menghitung rata-rata skor (X̄i), varians setiap butir (si2),
                  dan varians skor total konstruk (sY2) dengan rumus sampel tak bias
                  (N − 1):
                

                

                  

                    
Varians Butir
                      ke-i (si2):

                    

                      si2 =
                      
                        ∑ (Xij − X̄i)2
                        N − 1
                      
                      =
                      
                        N ∑Xi2 −
                          (∑Xi)2
                        N(N − 1)
                      
                    

                  

                  

                    
Varians Skor Total
                      Konstruk (sY2):

                    

                      sY2 =
                      
                        ∑ (Yj − Ȳ)2
                        N − 1
                      
                      =
                      
                        N ∑Y2 −
                          (∑Y)2
                        N(N − 1)
                      
                    

                  

                

              


              
              

                

                  Tahap 3
                  
Uji Validitas Butir — Korelasi Pearson Product Moment (rhitung)

                

                

                  Mengukur derajat asosiasi linier antara butir pernyataan ke-i dengan skor total konstruk
                  Y. Menggunakan rumus korelasi momen hasil-kali Pearson:
                

                

                  

                    rXY =
                    
                      N ∑XY −
                        (∑X)(∑Y)
                      √[ [ N ∑X2 −
                        (∑X)2 ] · [ N ∑Y2 −
                        (∑Y)2 ] ]
                    
                  

                

                

                  Signifikansi korelasi diuji menggunakan transformasi statistik t-Student dengan derajat
                  kebebasan df = N − 2:
                

                

                  

                    t =
                    
                      rXY √(N − 2)
                      √(1 − rXY2)
                    
                       |    df = N − 2
                  

                

                

                  Kriteria Keputusan Validitas:
                  
    
                    
  • VALID: Jika nilai rhitung >
                        rtabel pada taraf signifikansi α (default: 0.05, df
                      = N − 2) dan nilai probabilitas p < 0.05. Butir sahih
                      dan layak dianalisis lebih lanjut (Sugiyono, 2019; Azwar, 2018).
    • 
                    
  • GUGUR (TIDAK VALID): Jika rhitung ≤
                      rtabel atau p ≥ 0.05. Butir tidak mampu mengukur apa yang
                      seharusnya diukur dan direkomendasikan untuk didrop.
    • 
                  

                

              


              
              

                

                  Tahap 4
                  
Korelasi Butir-Total Terkoreksi (Corrected Item-Total Correlation)

                

                

                  Korelasi Pearson biasa rentan terhadap bias overestimasi (spurious correlation) karena butir
                  i ikut dijumlahkan ke dalam skor total Y. Metode Henrysson (1963) mengeliminasi
                  butir i dari skor total (Y−i = Y −
                  Xi):
                

                

                  

                    ri(Y−i) =
                    
                      riY sY −
                        si
                      √[ sY2 +
                        si2 − 2 riY sY
                        si ]
                    
                  

                

                

                  Kriteria Daya Beda Butir: Menurut Ebel & Frisbie (1991) serta Azwar (2018), butir
                  kuesioner memiliki daya pembeda yang memuaskan jika koefisien
                  ri(Y−i) ≥ 0.300. Butir dengan nilai di bawah 0.300
                  dianggap memiliki daya pembeda lemah dan berpotensi menjadi kontributor kebisingan (*noise*).
                

              


              
              

                

                  Tahap 5
                  
Uji Reliabilitas Skala — Koefisien Cronbach's Alpha (α)

                

                

                  Menguji konsistensi internal dari seluruh butir dalam merefleksikan konstruk laten secara serempak:
                

                

                  

                    α =
                    
                      k
                      k − 1
                    
                    ×
                    [ 1 −
                    
                      ∑i=1k si2
                      sY2
                    
                    ]
                  

                

                

                  Klasifikasi Nilai Reliabilitas (Hair et al., 2022; George & Mallery, 2020):
                  

                    α ≥ 0.900
                      : Istimewa / Excellent
                    0.800 ≤ α
                      < 0.900 : Baik / Good
                    0.700 ≤ α
                      < 0.800 : Dapat Diterima (Ambang Batas Riset)
                    0.600 ≤ α
                      < 0.700 : Meragukan (Riset Eksplorasi)
                    α < 0.600
                      : Tidak Reliabel (Ditolak)
                  

                

              


              
              

                

                  Tahap 6
                  
Diagnostik Butir Penggugur — Cronbach's Alpha if Item Deleted (α−i)

                

                

                  Menghitung ulang reliabilitas skala dengan mengeluarkan butir ke-i (k − 1
                  butir tersisa):
                

                

                  

                    α−i =
                    
                      k − 1
                      k − 2
                    
                    ×
                    [ 1 −
                    
                      ∑m ≠ i sm2
                      sY − i2
                    
                    ]
                  

                

                

                  Panduan Tindakan Perbaikan Instrumen:
                  
    
                    
  • Jika $\alpha_{-i} > \alpha_{\text{total}}$, berarti butir ke-$i$ justru menurunkan reliabilitas
                      keseluruhan instrumen. Menghapus butir $i$ akan meningkatkan konsistensi skala.
    • 
                    
  • Jika $\alpha_{-i} \le \alpha_{\text{total}}$, berarti butir ke-$i$ memperkuat reliabilitas
                      instrumen dan harus dipertahankan.
    •

Glosarium & Panduan Kolom Statistik Deskriptif &
              Normalitas

            Definisi matematis, rumus, makna statistik, dan
              standar acuan interpretasi
          

        

        
      


      

        
        

          search
          
        


        

          
          

            

              N
              N (Ukuran Sampel / Jumlah Responden Valid)
            

            

              
Definisi: Total banyaknya amatan atau responden yang memberikan jawaban valid pada
                butir indikator tersebut (tidak kosong / non-missing).

              
N = Jumlah responden dengan isian valid

              
Interpretasi: Dalam pemodelan SEM, Hair et al. (2022) menganjurkan ukuran sampel
                minimal 100 responden atau rasio 5–10 responden per parameter indikator yang diestimasi.

            

          


          
          

            

              Mean
              Mean (Rata-Rata Hitung Aritmatika)
            

            

              
Definisi: Titik berat atau rata-rata skor jawaban responden pada indikator/konstruk.
              

              

                X̄ = ∑j=1N
                    XjN
              

              
Interpretasi: Menunjukkan kecenderungan umum persepsi responden. Pada skala Likert
                1–5, skor rata-rata di atas 3.00 mengindikasikan kecenderungan persetujuan positif responden
                terhadap indikator.

            

          


          
          

            

              SE Mean
              SE Mean (Standard Error of the Mean / Galat Baku Rata-Rata)
            

            

              
Definisi: Pengukuran variabilitas dan presisi dari rata-rata sampel dalam mengestimasi
                rata-rata populasi yang sebenarnya. Menjawab pertanyaan seberapa akurat mean sampel mewakili parameter
                populasi.

              

                SEMean = s√N
              

              
Interpretasi & Panduan: Semakin kecil nilai SE Mean, semakin tinggi tingkat ketepatan
                dan keterpercayaan mean sampel. Digunakan untuk membentuk Selang Kepercayaan 95%: X̄ ± 1.96
                × SEMean.

            

          


          
          

            

              Median
              Median (Nilai Tengah Data)
            

            

              
Definisi: Skor observasi yang berada tepat di posisi tengah (persentil ke-50) saat
                seluruh data responden diurutkan dari nilai terendah ke tertinggi.

              
Interpretasi: Sangat tahan terhadap nilai pencilan ekstrem (robust to
                  outliers). Jika nilai Mean dan Median hampir identik, hal ini mengindikasikan distribusi data
                simetris.

            

          


          
          

            

              Modus
              Modus (Skor Terbanyak / Paling Sering Muncul)
            

            

              
Definisi: Kategori skor pada skala pengukuran yang dipilih oleh frekuensi responden
                terbanyak.

              
Interpretasi: Memberikan gambaran pilihan tipikal yang paling populer di kalangan
                responden penelitian.

            

          


          
          

            

              StDev
              StDev (Standar Deviasi / Simpangan Baku)
            

            

              
Definisi: Ukuran sebaran atau dispersi amatan data di sekitar rata-rata hitung.

              

                s = √[ ∑ (Xj
                    − X̄)2N − 1 ]
              

              
Interpretasi: Semakin kecil nilai StDev, jawaban responden semakin homogen / seragam.
                Semakin besar nilai StDev, persepsi responden semakin heterogen / bervariasi.

            

          


          
          

            

              Varians
              Varians (Kuadrat Simpangan Baku)
            

            

              
Definisi: Rata-rata kuadrat jarak deviasi setiap observasi terhadap mean sampel.

              

                s2 = ∑ (Xj
                    − X̄)2N − 1
              

            

          


          
          

            

              Min & Max
              Skor Minimum (Min) & Skor Maksimum (Max)
            

            

              
Definisi: Nilai terendah dan tertinggi yang riil diberikan oleh responden dalam
                dataset.

              
Interpretasi: Berfungsi mendeteksi adanya salah input data (data entry
                  error), misalnya ada skor 6 pada kuesioner skala 1–5.

            

          


          
          

            

              Range
              Range (Rentang / Jangkauan Data)
            

            

              
Definisi: Selisih antara nilai maksimum dan nilai minimum data: R =
                Xmax − Xmin.

            

          


          
          

            

              TCR (%)
              TCR (%) (Tingkat Capaian Responden)
            

            

              
Definisi: Persentase capaian rata-rata empiris jawaban responden terhadap nilai skala
                teoritis maksimum yang dapat dicapai.

              

                TCR = ( X̄Skala
                    Maksimum ) × 100%
              

              
Kriteria Interpretasi Kategori Capaian (Arikunto, 2019; Sugiyono, 2018):

              
    
                
  • ≥ 81%: Sangat Baik / Sangat Tinggi
    • 
                
  • 66% – 80%: Baik / Tinggi
    • 
                
  • 51% – 65%: Cukup / Sedang
    • 
                
  • 36% – 50%: Kurang / Rendah
    • 
                
  • < 36%: Sangat Kurang / Sangat Rendah
    • 
              

            

          


          
          

            

              Skewness & Z-Score
              Skewness, Std. Error Skewness, & Z-Score Skewness
            

            

              
Definisi: Pengukuran derajat ketidaksimetrisan (kemiringan) kurva distribusi data di
                sekitar mean.

              

                

                  SEskew = √[ 6N(N
                      − 1)(N − 2)(N + 1)(N +
                      3) ]
                

                

                  Zskew = SkewnessSEskew
                

              

              
Kriteria Keputusan Normalitas Univariat:

              
    
                
  • Jika −1.96 ≤ Zskew ≤ +1.96 (α = 0.05),
                  kemiringan kurva tidak berbeda nyata dari distribusi normal (Hair et al., 2022).
    • 
                
  • Jika Zskew > +1.96: Kurva menceng positif ke kanan (positively
                    skewed).
    • 
                
  • Jika Zskew < −1.96: Kurva menceng negatif ke kiri (negatively
                    skewed).
    • 
              

            

          


          
          

            

              Kurtosis & Z-Score
              Kurtosis, Std. Error Kurtosis, & Z-Score Kurtosis
            

            

              
Definisi: Pengukuran derajat keruncingan (peakedness) atau kerataan kurva distribusi
                data relatif terhadap distribusi normal mesokurtik.

              

                

                  SEkurt = 2 × SEskew × √[ N2 − 1(N −
                      3)(N + 5) ]
                

                

                  Zkurt = KurtosisSEkurt
                

              

              
Kriteria Keputusan Normalitas Univariat:

              
    
                
  • Jika −1.96 ≤ Zkurt ≤ +1.96 (α = 0.05), puncak
                  kurva sesuai dengan asumsi normal univariat.
    • 
                
  • Jika Zkurt > +1.96: Kurva bersifat runcing tajam (leptokurtik).
    • 
                
  • Jika Zkurt < −1.96: Kurva bersifat mendatar tumpul
                  (platikurtik).
    • 
              

            

          


          
          

            

              Distribusi Univariat
              Kesimpulan Distribusi Univariat untuk PLS-SEM
            

            

              
Kaidah Evaluasi: Dinyatakan Normal Univariat jika kedua nilai Z-Score
                Skewness dan Kurtosis memenuhi interval [−1.96, +1.96]. Jika salah satu melebihi ambang batas,
                data dikategorikan Cenderung Asimetris / Non-Normal.

              

                💡 Catatan Metodologi PLS-SEM (Hair et al., 2022; Rigdon et al., 2017): Metode PLS-SEM
                bersifat non-parametrik (bebas asumsi normalitas sebaran data multivariat). Pengujian
                normalitas univariat disajikan untuk transparansi karakteristik empiris data penelitian Anda.
